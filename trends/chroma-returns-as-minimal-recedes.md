# Chroma returns as minimal recedes

Status: `emerging`

## Observation

Same dataset and batches as the photography signal. Among style-tagged sites, `Colorful` share rose 29.2% → 50.6% (+21.4pp; 1,095 → 253 tagged sites) while `Minimal` collapsed 57.0% → 27.7% (-29.3pp). Median cover saturation rose 7.8 → 11.6 (+48.7% relative; directional only). Colorful rises on both dark grounds (4.7% → 15.8%) and light grounds (11.8% → 32.5%), while conditional `Dark` share itself is flat (+0.2pp) — the raw `Dark` increase was a tag-coverage artifact.

- **Billow** runs a saturated blue accent system across a light ground.
- **Alike** combines color accents and photography on a dark ground.
- **Jarcos** drops a saturated gradient artwork against oversized black type.

## Inference

The muted/minimal default is giving way to saturated accent color across themes. This is not a dark-mode move: theme preference is unchanged and chroma rises within both themes. Single curated source, so curation-taste drift cannot be excluded.

## Fit

Palette direction for marketing and launch sites; brand accent systems that must read against both light and dark contexts.

## Avoid

Reading this as "dark mode rising" (an artifact of tag coverage, not a theme shift); treating it as license for full-saturation backgrounds — median saturation remains low, so the move is accent-led, not flood-fill.
