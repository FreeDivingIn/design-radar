# Editorial scaffolding carries grouping

Status: `stable`

## Observation

Current expressive websites continue to make structure legible through type scale, spacing, grids, labels, indices and sequence while persistent surfaced containers carry less of the grouping load.

- **Arc’teryx System 0** uses a dynamic grid and flexible layouts to stage a complex circularity system as a guided narrative.
- **ANDMADE** exposes an index-like case structure with dated entries and `Txt / Img` representation modes; hierarchy is carried by scale, rhythm and the underlying grid.
- **Studio Loop** uses numbered services, year/client sequences, oversized language and media rhythm instead of wrapping every section in a card.
- **Site of Sites’ current September batch** independently surfaces System 0 and ANDMADE among contemporary curated sites.

## Inference

On low-to-moderate-density expressive sites, spatial and typographic relationships remain a viable primary boundary mechanism. This is a current baseline rather than a newly emerging style: recurrence is clear, but the 90-day window does not establish that the mechanism itself is newly accelerating.

## Fit

Brand sites, launches, editorial stories and portfolios where browsing, identity and narrative matter more than rapid object comparison.

## Avoid

Dense enterprise, commerce or data workflows where visible containers communicate selection, state, ownership, drag targets or comparison units. “Remove cards” is not a valid rule.

## Evidence

- [Arc’teryx System 0 — forpeople](https://www.forpeople.com/projects/arcteryx-system0-circularity/) — dynamic grid, flexible layouts and staged guest journey.
- [ANDMADE](https://andmade.jp/) — live site exposes dated index structure and `Txt / Img` modes.
- [Studio Loop](https://www.studioloop.com.br/) — live site uses numbered services and repeated temporal/project sequences.
- [Site of Sites](https://www.siteofsites.co/) — September 2026 curation independently surfaces System 0 and ANDMADE.

## Uncertainty

Evidence is strongest for expressive websites, not application UI. Keep `stable` unless later batches show a directional change in task-oriented products.
