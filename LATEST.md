# Latest — 2026-09-10

Working memory only. Two signals currently clear the promotion threshold.

## Provenance becomes a reusable primitive — `emerging`

**Observation:** The Kithmore, The Rampant Club, and Ytri translate place-specific evidence—found signpainting, golf ephemera, heraldic/glass geometry, settlement history and local forms—into type, marks, patterns, layout or physical details. **Inference:** heritage is being treated more as traceable source material for a system than as a generic retro surface. **Fit:** place-led hospitality, culture and membership brands. **Avoid:** weak provenance, utility products, or culturally reductive borrowing. → `trends/provenance-to-primitives.md`

## Editorial scaffolding carries grouping — `emerging`

**Observation:** Arc’teryx System 0, ANDMADE and Studio Loop use scale, spacing, grids, labels, indices and narrative sequence as primary page structure, with persistent card chrome playing a smaller role. **Inference:** expressive brand/portfolio surfaces are shifting grouping work toward typographic and spatial hierarchy. **Fit:** low-to-moderate-density brand, launch and portfolio experiences. **Avoid:** dense transactional/data workflows where explicit object and state boundaries aid speed or accessibility. → `trends/editorial-scaffolding-over-card-chrome.md`
